Why Firebase?
Google Firebase provides a generous 100% free tier that hosts documents in Firebase Cloud Storage and broadcasts status updates to all team members instantly via the Realtime Database.
Need a free Firebase database? Open Firebase Console
Quick 2-Minute Setup:
  1. Create a free project at console.firebase.google.com.
  2. Under Build, enable Realtime Database (in test mode) and Storage (in test mode).
  3. Go to Project Settings -> General -> Add Web App (</>) -> copy the config object and paste it above!

Deploying to GitHub Pages

Your repository is located at: https://github.com/DilushaHesaranga/report-finalization

  1. Save this HTML file as index.html in your repository.
  2. Commit and push it to the main branch.
  3. On GitHub, go to Settings > Pages.
  4. Under Branch, select main and / (root), then click Save.
  5. Within 1-2 minutes, your website will be live at:

Report Submission Instructions

1. Progress reporting: Clearly describe the progress you have made up to the date of submission.

2. Industry Sessions: If any session is scheduled to be conducted, mention those sessions separately. Link each session you had with the company to its relevant section in the report.

3. Workload Decomposition: The group report is distributed across 14 members according to specialization, from Company Background (Member 1) to Quality Assurance & Appendices (Member 14).

4. Status Workflow:

  • Not Done: Work not yet started or submitted.
  • To be revised: Draft received, needs edits/corrections.
  • Need another answer: Missing information from the company or requires clarification.
  • Finished: Member's piece is finalized and approved.
  • Added to the report: Officially compiled into master document.
